# Lab 2 - Interactive Quiz & Weather Dashboard

This project was created as part of the Full Stack Development Lab in the 5th semester.

## Features

* Interactive 5-question quiz
* 30-second timer for each question
* Automatic score calculation
* Leaderboard saved using browser localStorage
* Real-time weather search consuming Open-Meteo public REST API

## Tech Stack

* **HTML5** - Page structure and forms
* **CSS3** - Layout, styling, cards, and responsive design
* **JavaScript (ES6)** - Dynamic DOM updates, timers, localStorage, and asynchronous fetch() API
